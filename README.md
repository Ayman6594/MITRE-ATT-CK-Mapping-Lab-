# MITRE-ATT-CK-Mapping-Lab-
Isolated MITRE ATT&amp;CK detection engineering lab built on VMware Workstation with Kali, Windows 11 + Sysmon, and Wazuh. Simulates real attack techniques, maps them to ATT&amp;CK, and includes a root-caused false positive fix and a confirmed detection gap, backed by evidence, not assumptions.
